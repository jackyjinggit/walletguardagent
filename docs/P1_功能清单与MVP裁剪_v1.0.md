# P1 功能清单与 MVP 裁剪 v1.0

## 目标

通用采购协作：协助记账（合规）+ 协助决策（多人协作 + 审计追溯）+ 最后静态跳转到 Monad 链上页面（采购账本公示 + 决策可验证）。

范围不绑定特定单位类型（政府采购 / 事业单位 / 公司 / 学校 / 医院通用）。

## 功能清单

| # | 功能 | 说明 | 负责 |
|---|---|---|---|
| F1 | 采购录入 | 录入采购申请（品目 / 数量 / 预算 / 供应商） | 蒋平 |
| F2 | 审批流 | 多级审批（采购员 / 主管 / 财务 / 审计） | 蒋平 |
| F3 | 账本展示 | 展示采购订单与花费明细 | 蒋平 |
| F4 | 钱包接入 | WalletConnect 集成 | 蒋平 |
| F5 | 链上跳转 | Monad 静态跳转页（独立页 + explorer 链接） | 蒋平 |
| F6 | 交易签名 | 最后交易 owner 签 Approve | 蒋平 |
| F7 | 采购合约 | 采购订单合约（Solidity 多签） | 董鹏 |
| F8 | 记账上链 | 记账事件 + 决策 hash 上链 | 董鹏 |
| F9 | 合约部署 | Monad 测试网 deploy | 董鹏 |
| F10 | 数据接入 | 采购数据接入 | 刘志 |
| F11 | AI 推理 | 合规校验 + 决策建议 | 刘志 |
| F12 | 签名代发 | owner 签名代发 | 刘志 |
| F13 | 事件订阅 | 链上事件订阅 | 刘志 |
| F14 | 审计报告 | 审计报告生成 | 刘志 |
| F15 | 异常检测 | 异常检测 | 刘志 |
| F16 | 数据汇总 | 链上 / 链下数据汇总 | 刘志 |
| F17 | 决策追溯 | 决策可追溯 | 刘志 |

## MVP 裁剪

| 优先级 | 功能 | 说明 |
|---|---|---|
| **P0（必须）** | F1 / F3 / F5 / F7 / F10 / F11 / F14 | 采购录入 + 账本 + 合约 + 数据 + AI 建议 + 审计报告 = 端到端跑通 |
| **P1（应该）** | F2 / F4 / F8 / F12 / F13 / F15 / F16 / F17 | 审批 + 钱包 + 上链 + 签名 + 事件 + 异常 + 汇总 + 追溯 |
| **P2（可选）** | F6 / F9 | owner 签 Approve + 测试网部署 = 演示阶段可后置 |

## 当前状态（2026-10-16）

- 本地交互原型已就位（聊天首页 + 预算摘要 + 详情抽屉）。
- 采购付款、链上操作、报告交付均为模拟。
- 这**不代表** WalletConnect、多签或审计能力已完成。

## 边界

- 范围不绑定特定单位类型（泛化）。
- 演示与评审阶段 = P0 跑通即可。
- 真实合约部署与链上审计 = 后续阶段。

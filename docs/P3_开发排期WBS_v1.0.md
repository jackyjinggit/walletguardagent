# P3 开发排期 WBS v1.0

## 目标

通用采购协作：协助记账（合规）+ 协助决策（多人协作 + 审计追溯）+ 最后静态跳转到 Monad 链上页面。

## 关键日期

| 段 | 期限 | 内容 | 验收 |
|---|---|---|---|
| **D0** | 10-16 | 启动会 | 角色分工确认 |
| **E1** | 10-17~19 | mock 端到端 | 本地原型跑通 |
| **E2** | 10-20~24 | Monad 测试网端到端 | 合约部署 + 链上事件订阅 |
| **E3** | 10-25~28 | 完整 demo | UI + 链上跳转 + 演示 |
| **E4** | 10-29~31 | 评审材料 | 报告与材料齐备 |

## 当前状态（2026-10-16）

- W1 本地原型（聊天首页 + 预算摘要 + 详情抽屉）已就位。
- 采购付款、链上操作、报告交付均为模拟。
- 这**不代表** WalletConnect、多签或审计能力已完成。

## 边界

- 排期服从依赖与产能，不追求精确到没有依据的日期。
- 演示与评审阶段以 P0 跑通为准。
- 范围不绑定特定单位类型（泛化）。
